## 2. Logic Chain

1. In *Observation A.1*, 5 concurrent quotation conversion requests created 4 duplicate projects (`4 !== 1`) because PostgreSQL Read Committed transactions do not prevent concurrent inserts when rows are queried before being committed.
2. In `backend/routes/tenant/quotations.js`, an atomic conditional lock was added:
   `const lockResult = await prisma.quotation.updateMany({ where: { id, tenantId, isLocked: false }, data: { isLocked: true, status: 'ACCEPTED', acceptedAt: quotation.acceptedAt || new Date() } });`
   Under PostgreSQL row-level locking, exactly one concurrent transaction transitions `isLocked: false -> true` (`lockResult.count === 1`). All concurrent requests get `lockResult.count === 0`, enter a short polling loop (100ms intervals up to 2.5s), and return the committed project with HTTP 200.
3. In *Observation A.1*, 5 concurrent lead conversion requests caused interactive transaction timeouts (P2028: `timeout 5000 ms passed`) and crashed with HTTP 500.
4. In `backend/routes/tenant/crm.js`, an atomic conditional lock was added:
   `const lockResult = await prisma.lead.updateMany({ where: { id, tenantId, status: { not: 'WON' } }, data: { status: 'WON' } });`
   Interactive transaction options `{ timeout: 30000, maxWait: 10000 }` were applied, and concurrent requests with `lockResult.count === 0` poll and return the created customer/project with HTTP 200. Graceful fallbacks in catch blocks query and return the project rather than throwing 500.
5. When a lead is converted with a linked quotation, `backend/routes/tenant/crm.js` was enhanced to automatically populate `projectMaterialRequirement` BOM items from `latestQuote.items`, guaranteeing BOM consistency across lead and quotation workflows.
6. In *Observation A.1*, 9 statutory identity leaks were detected across `web-client/src/components/pdf/MsedclFormsPDF.tsx`, `web-client/src/app/tenant/quotations/page.tsx`, and `web-client/src/components/quotations/QuotationDetailModal.tsx`.
7. All 13 instances of `"SHRI. SURENDRA RAMBHAU THAKRE"`, `"SURENDRA RAMBHAU THAKRE"`, `"RAVI DODKUJI KAWALE"`, `"RAMBHAU THAKRE"`, `"M/S EKVARTA ENERGY SOLUTIONS"`, `"EKVARTA ENERGY SOLUTIONS"`, `"410022120526"`, `"413472965142"`, address fallbacks, and the hardcoded Adani serials array were replaced with dynamic accessors defaulting to empty strings `""` or empty arrays `[]`.
8. In `backend/test/m4AdversarialChallenges.test.js`, `assert.equal(leaksFound.length, 0)` was enforced, and test fixtures were isolated so that both burst tests test independent, real concurrency paths.
9. As evidenced in *Observation B*, all 14 adversarial tests passed (100%), all regression suites passed (101 total tests across suites), and the Next.js production build succeeded with 66/66 routes.
